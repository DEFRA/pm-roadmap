Upload items from spreadsheet

Use this page to create or update roadmap items in bulk. Download the template spreadsheet to get started — fill in the Roadmap ID on cell B1, then add one item per row from row 4 onwards.

  • If an item with the same Title already exists on that roadmap it will be updated.
  • Tags must already exist in the system — use the Tags admin to add any missing ones first.
  • Dates should be formatted as DD/MM/YYYY.
